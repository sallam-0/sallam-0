A production-style real-time data platform for financial transaction analytics and fraud detection.
- Built a **CDC pipeline** (Debezium + Kafka) to ingest transactional data from MSSQL
- Real-time enrichment, feature engineering, and ML-based fraud scoring with **Apache Flink**
- Orchestrated batch & streaming **ELT** workflows with **Airflow**, loading into **Snowflake**

`Python` `SQL` `Kafka` `Debezium` `Apache Flink` `Airflow` `dbt` `Snowflake` `Docker` `S3`

### 🔹 GCP E-Commerce Data Platform
A scalable, serverless, end-to-end data pipeline on Google Cloud Platform.
- Ingests, processes, and stores e-commerce data from multiple sources into **BigQuery**
- Streaming pipeline with **deduplication** (exact + fuzzy), dead-letter queues, and incremental loads
- Modern architecture combining **GCS (data lake)**, **BigQuery (warehouse)**, and **FastAPI + Firestore** for real-time access
- Advanced analytics: price tracking, seller trust scoring, sentiment analysis, automated price alerts

`Python` `GCP (Cloud Run, Pub/Sub, Dataflow, BigQuery, Cloud Storage, Firestore, Cloud Scheduler, Secret Manager)` `SQL`

An end-to-end dimensional data warehouse for retail analytics.
- Star schema modeling for analytical efficiency
